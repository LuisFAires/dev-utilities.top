# Dev Utilities

A collection of free developer tools that run entirely in the browser. Published at https://dev-utilities.top.

## Tools

- **PHP uniqid() Decoder**: extracts the Unix timestamp from the first eight hexadecimal characters of a `uniqid()` and displays it in UTC and local time.
- **Excel/CSV to SQL IN Generator**: converts pasted Excel or CSV column values into a SQL-ready `IN (...)` clause.
